# YouTube на AWS

YouTube может вернуть `Sign in to confirm you're not a bot` для IP облачного провайдера. При этом `yt-dlp` способен
вернуть код 0, название и описание из страницы, но пустой список субтитров. Это **не доказательство отсутствия субтитров**.
Куни сохраняет доступные метаданные, но сообщает о блокировке, а не об отсутствии дорожек.

## Настроенный маршрут

На текущем сервере используется один работающий узел предоставленной владельцем VLESS-подписки, через Xray-core.
Локальный HTTP-прокси слушает только `127.0.0.1:11990`; новых входящих портов AWS открывать не нужно.

```toml
[capabilities.youtube]
enabled = true
proxy_url = "http://127.0.0.1:11990"
```

Эта настройка применяется **и к извлечению метаданных, и к скачиванию субтитров**: подписанные ссылки могут зависеть
от адреса выхода. Telegram и API Agnes не используют этот маршрут. Конфигурация Xray дополнительно разрешает через
прокси только домены YouTube и его медиа/API, остальные назначения отклоняются. Системные маршруты и VPN/TUN не меняются.
Прокси HTTP/HTTPS можно задать и без Xray, если он уже имеется. SOCKS-конфигурация здесь не поддерживается.

## Файлы и восстановление

- `data/youtube_proxy/config.json` — **секретные** параметры выбранного VLESS-узла; файл `600`, каталог `700`.
  Попадает в резервные копии `data/`. Исходная ссылка подписки не сохраняется в проекте.
- `data/youtube_proxy/client.json` — версия клиента, официальный URL архива, SHA-256 и пути.
  Шаблон без секретов: `deploy/youtube-proxy-client.json`.
- `/home/ubuntu/.local/bin/kuni-xray` — официальный бинарный Xray-core. Версия и SHA-256 архива зафиксированы в манифесте;
  при восстановлении бинарник можно скачать заново и проверить перед распаковкой.
- `deploy/kuni-youtube-proxy.service` — локальный прокси; `deploy/kuni-youtube.conf` — зависимость сервиса Куни.

```bash
sudo systemctl status kuni-youtube-proxy
sudo systemctl restart kuni-youtube-proxy
```

При смене ключей/адреса узла или окончании подписки нужно обновить приватный `config.json` и перезапустить прокси.
Автообновления подписки и автоматического перебора узлов нет. Не публикуйте конфигурацию или саму ссылку подписки.

## Проверка

Проверяйте получение **непустого текста**, а не только список языков или код завершения:

```python
import asyncio
from kuni.youtube import read_youtube_video

result = asyncio.run(read_youtube_video("https://youtu.be/WosdSVW3bZU", "ru"))
assert result["transcript"] and result["transcript"]["text"]
print(result["transcript"]["language"], len(result["transcript"]["text"]))
```

Прокси тоже может оказаться заблокирован YouTube. Ошибка доступа не должна превращаться в утверждение, что ролик не
содержит субтитров. Ограничение текста в 16 000 символов сохранено; `truncated=true` означает, что это только фрагмент.
